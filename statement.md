# Project Statement

## Campus Course & Records Manager (CCRM)

The **Campus Course & Records Manager (CCRM)** is a Java-based application developed to efficiently manage academic information within a campus environment. The system provides a centralized way to maintain student records, course details, enrollments, grades, and academic performance.

The project aims to reduce manual record management and provide a structured, reliable, and easy-to-use system for handling academic data. It includes features such as student and course management, enrollment with credit-limit validation, grade recording, GPA calculation, CSV import/export, backup and restore, and report generation.

CCRM also demonstrates core **Object-Oriented Programming (OOP)** and Java programming concepts, including encapsulation, inheritance, abstraction, polymorphism, interfaces, exception handling, collections, Stream API, file handling, and design patterns.

### Objective

The main objective of CCRM is to provide an organized and efficient solution for managing campus academic records while demonstrating practical implementation of Java and OOP concepts.

### Key Features

- Student management
- Course management
- Student enrollment
- Credit-limit validation
- Grade recording and GPA calculation
- Search and update functionality
- CSV import and export
- Data backup and restore
- Reports and statistics
- Exception handling and data validation

### Technologies Used

- **Programming Language:** Java
- **Concepts:** OOP, Collections, Streams, File I/O, NIO.2, Exception Handling
- **Data Storage:** File/CSV-based storage

### Expected Outcome

The system provides a simple and structured platform for maintaining academic records and demonstrates how Java programming and OOP principles can be applied to solve a real-world campus management problem.
